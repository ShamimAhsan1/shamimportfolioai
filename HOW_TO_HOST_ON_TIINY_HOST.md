# How to Host Shamim Ahsan Portfolio on Tiiny Host (tiiny.host)

This folder contains a **100% Tiiny Host-optimized** export of your portfolio website.

---

## ⚡ 3-Step Instant Deployment to Tiiny Host

1. **Open Tiiny Host**:
   Go to [https://tiiny.host](https://tiiny.host) in your web browser.

2. **Drag & Drop the ZIP File**:
   Drag and drop the file:
   👉 **`shamim-portfolio-tiinyhost.zip`**
   *(Located in this folder, and also copied directly to your Desktop)* into the upload box on Tiiny Host.

3. **Pick a Link Name & Click Launch**:
   - Enter your preferred sub-domain name (e.g., `shamim-ahsan` or `shamim-portfolio`).
   - Click **"Launch"** or **"Publish"**.
   - Your portfolio is now instantly live on the web at `https://shamim-ahsan.tiiny.site`! 🎉

---

## 🌟 Why This Export is 100% Tiiny Host Friendly:

- **Ultra-Lightweight (~1.0 MB)**: Fits comfortably within Tiiny Host's 3MB free plan limit.
- **Root-level `index.html`**: Guaranteed root hierarchy so Tiiny Host recognizes your homepage immediately.
- **Relative Asset Paths**: All CSS, JavaScript, and images are linked using relative paths (`assets/...`, `styles.css`, `script.js`).
- **Unix Forward-Slash Compatibility**: All zip entries use forward slashes (`/`) so Tiiny Host's Linux cloud servers extract assets smoothly without broken images.
- **Zero Server Dependencies**: Pure static frontend that runs with blazing speed on Tiiny Host's global CDN.
